# SOP 函数、维度与可视化

当前实现只包含 NeuroEA 的 SOP，不包含 BBOB。网页内 `SOP F#` 指下列代码版本的函数编号。

源实现：`NeuroEA_GEA_torch/Problems/Single_objective_optimization/Simple_SOPs/SOP_F{5,8,9,10}.py`，读取自本地 `source_H_development` 版本。网页使用 JavaScript 双精度，支持 **D=2、3、10，默认 D=10**。保留目标公式、逐维平移和原边界，没有随机旋转或人为设置陷阱起点。

令实际决策向量为 `x`，上界为 `U`；平移 `sᵢ=iU/(D-1)`，`i=0,…,D-1`；`z=x-s`。这与原代码 `linspace(0,U,D)` 一致。

| 编号    | 函数       | 原边界           | D 维公式                                                |
| ------- | ---------- | ---------------- | ------------------------------------------------------- |
| SOP_F5  | Rosenbrock | `[-30,30]^D`     | `Σᵢ₌₁…D₋₁ [100(zᵢ₊₁-zᵢ²)²+(zᵢ-1)²]`                     |
| SOP_F8  | Schwefel   | `[-500,500]^D`   | `-Σ zᵢ sin(sqrt(abs(zᵢ)))`                              |
| SOP_F9  | Rastrigin  | `[-5.12,5.12]^D` | `Σ(zᵢ²-10 cos(2πzᵢ)+10)`                                |
| SOP_F10 | Ackley     | `[-32,32]^D`     | `-20 exp(-0.2 sqrt(mean(z²)))-exp(mean(cos(2πz)))+20+e` |

## 搜索维度与地图维度

GA 的交叉和突变、PSO 的速度和个人最佳、DE 的差分和交叉均作用于**全部 D 个坐标**。每个候选解、最佳解、历史足迹均保存完整向量。初始化在整个 D 维可行域均匀采样，三队使用完全相同的初始向量；算法有独立随机流。

地图是两个视图的叠加：

- **底图是二维切片**：所选横纵坐标自由变化，其余坐标固定在页面列出的数值。默认经过可行域中心；可以取参考最优向量，或某队当前最佳解的快照。取快照后保持固定，点击“更新切片”才重新取值。
- **小点和足迹是二维投影**：完整候选向量只取所选两维绘制。不同高维解可以投影到同一点；小点不一定落在背景切片上。悬停地图显示的是切片 f，并非该处粒子的完整目标值。
- **平行坐标图展开完整解**：彩线对应三队的完整最佳解，虚线对应已知参考最优；每个坐标按原边界线性归一化，U/L 为原上/下界。悬停彩线可查看实际坐标值。它显示解的坐标，不表示逐维目标贡献。
- **成绩、误差曲线和成功判断按完整 D 维目标计算**。地图换轴、切换或更新切片不改变搜索状态、随机流、代数或成绩。切换 D 会重新开局。自由高斯地形保留 D=2。

地图颜色在当前切片采样求最小值与最大值，再按 `1-log1p(f-f_slice_min)/log1p(f_slice_max-f_slice_min)` 缩放；这用于呈现切片内部结构。不同切片的颜色不可直接比较，颜色不定义最优值或胜负。

D=3 已有三个决策坐标，再加目标值就是四个量；将目标高度直接当作第三个决策坐标会混淆二者，因此这里对 D=3 同样使用可切换坐标的切片和投影。

## 实际可行域与参考最优

平移后按原边界求最优，不能沿用未平移函数的最优值。

- **F5，D=2**：未约束最优点 `(1,31)` 不可行。约束最优为 `(x,30)`，`400x³+2x-2=0`，`x≈0.16126202314`，`f*≈0.771109685344`。
- **F5，D=3/10**：完整目标函数参与优化，但当前没有核定约束全局最优值。网页显示原始 **f**，仅比较目标值，不宣称解出、不绘制最优参考线。零只是下界，不当作可达的最优值。
- **F8，各维度**：可分离求解。第 i 维的平移域为 `[L-sᵢ,U-sᵢ]`；枚举该区间端点、零点和全部驻点。令 `t=sqrt(abs(z))`，驻点满足 `2sin(t)+t cos(t)=0`，使用分段括区间与二分求根，随后合并各维最小值。D=2 时 `f*≈-1311.710963248`，D=10 时 `f*≈-6434.236855`。原类 `get_optimum()` 的 `-418.9829*D` 没有适配平移后的可行域，网页不采用它。
- **F9/F10，各维度**：最优向量就是 `s`，`f*=0`，最后一个坐标在上边界。Ackley 浮点计算可能有约 `1e-15` 残差。

已有最优参考的函数显示 `Δf=max(0,f-f*)`，完整向量达到 `Δf≤1e-3` 才算解出；同一代达到目标算并列。整局固定 **100 代**。F5 高维显示 f，不做成功判定。内部最大化接口为 `1/(1+score)`，其中 score 是 Δf 或 F5 高维的非负 f。趋势图按对数显示，范围 `1e8` 至 `1e-8`，超出范围裁切；队伍读数保留实际量级。

`tests/sop-reference.json` 保留二维参考；`tests/sop-high-d-reference.json` 保存直接执行原 Python `cal_obj` 的 D=3/10 float64 参考点及源文件 SHA-256。高维参考覆盖四个函数、两种维度、各15个向量，包括随机点和边界点。Node 测试对照原数值，并检查完整向量、边界、单调历史、共享初始化和视角独立性。

## 100 代小规模难度检查

配置：D=10，每队36个体，100代，seed=42–61。GA突变0.12、PSO惯性0.729、DE差分0.8，其余默认。PSO 的速度上限逐坐标为0.07，以避免维数上升后每维步长被统一范数截断压小。各算法公式见源码。

| 函数 | GA 成功局数 | PSO 成功局数 | DE 成功局数 |
| ---- | ----------- | ------------ | ----------- |
| F8   | 0/20        | 0/20         | 0/20        |
| F9   | 0/20        | 0/20         | 0/20        |
| F10  | 0/20        | 0/20         | 0/20        |

成功阈值均为严格的 `Δf≤1e-3`。这说明该网页配置在100代内无法轻易求到指定精度；仍可从误差下降和完整解向量观察策略差别。F5 高维没有成功计数，仅记录最终原始 f。逐种子分数见 [sop-difficulty.json](sop-difficulty.json)。

复查：`node scripts/check-difficulty.cjs`（默认D=10），或追加 `2` / `3` / `10` 指定维度。数据对应固定参数与当前实现，交互中改参数会改变结果。这是按代演示，不是等函数评估预算的性能比较。

早期 D=2、120代、旧版算法的历史记录保留在 [sop-difficulty-d2-120-archive.json](sop-difficulty-d2-120-archive.json)，不作为当前结果。

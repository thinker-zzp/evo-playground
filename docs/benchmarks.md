# SOP 二维函数与来源

当前实现只包含 NeuroEA 的 SOP，不包含 BBOB。网页内 `SOP F#` 指下列代码版本的函数编号。

源实现：`NeuroEA_GEA_torch/Problems/Single_objective_optimization/Simple_SOPs/SOP_F{5,8,9,10}.py`，读取自本地 `source_H_development` 版本。网页为 JavaScript 双精度的 D=2 实现，保留目标公式、逐维平移和原边界。没有随机旋转、没有刻意将起点放入陷阱，也没有改变函数来增加难度。

将实际决策变量记为 `(x,y)`，上界为 `U`，原代码 `linspace(0,U,D)` 在 D=2 时给出平移向量 `(0,U)`，因此 `z=(x,y-U)`。

| 编号    | 函数       | 边界            | D=2 公式                                                |
| ------- | ---------- | --------------- | ------------------------------------------------------- |
| SOP_F5  | Rosenbrock | `[-30,30]²`     | `100*(z₂-z₁²)²+(z₁-1)²`                                 |
| SOP_F8  | Schwefel   | `[-500,500]²`   | `-Σ zᵢ sin(sqrt(abs(zᵢ)))`                              |
| SOP_F9  | Rastrigin  | `[-5.12,5.12]²` | `Σ(zᵢ²-10 cos(2πzᵢ)+10)`                                |
| SOP_F10 | Ackley     | `[-32,32]²`     | `-20 exp(-0.2 sqrt(mean(z²)))-exp(mean(cos(2πz)))+20+e` |

## 实际可行域的参考最优

平移后必须按原可行域求最优，不能直接沿用未平移函数的最优值。

- **F5**：未约束的最优点 `(1,31)` 在原边界之外。可行最优为 `(x,30)`，其中 `400x³+2x-2=0`，`x≈0.16126202314`，`f*≈0.771109685344`。
- **F8**：第二维平移后的范围是 `[-1000,0]`。网页枚举每一维的端点、零点和全部驻点；令 `t=sqrt(abs(z))`，驻点满足 `2sin(t)+t cos(t)=0`，使用分段括区间与二分求根。二维可行最优点约为 `(420.96874636,-394.72139486)`，`f*≈-1311.710963248`。原类 `get_optimum()` 中的 `-418.9829*D` 没有适配这一平移后的可行域，网页不将其作为成功阈值。
- **F9**：最优点 `(0,5.12)`，`f*=0`，在上边界。
- **F10**：最优点 `(0,32)`，`f*=0`，在上边界（浮点计算有约 `1e-15` 残差）。

`tests/sop-reference.json` 保存了直接执行原 Python `cal_obj` 的 float64 参考点与源文件 SHA-256。Node 测试对照这些数值，并检查可行最优点和搜索不变量。

## 目标值、颜色与胜负

- 实际算法最小化 `f`；为复用最大化接口，用严格单调的 `1/(1+max(0,f-f*))` 保存 fitness。
- 队伍数值显示 `Δf=max(0,f-f*)`，达到 `Δf≤1e-3` 才算解出。不会因为地图颜色接近最亮就判成功。
- 地图使用 `1-log(1+Δf)/log(1+Δf_grid_max)` 着色，网格只用于颜色范围，不用于定义最优值或胜负。
- 曲线按误差对数显示，显示范围 `1e8` 至 `1e-8`，超出范围会在图边界裁切；队伍读数仍显示实际误差。
- SOP 地形固定，seed 只改变搜索初始化与算法随机流。所有队伍共用整个可行域均匀采样的初始位置。
- 标准函数不允许“搬峰”；自由高斯地形仍可编辑。

## 小规模难度检查

配置：D=2，每队36个体，120代；seed=42–61；GA突变0.12、PSO惯性0.729、DE差分0.8，其余参数保持实现默认；成功阈值 `Δf≤1e-3`。

| 函数 | GA 成功局数 | PSO 成功局数 | DE 成功局数 |
| ---- | ----------- | ------------ | ----------- |
| F5   | 20/20       | 20/20        | 20/20       |
| F8   | 11/20       | 6/20         | 18/20       |
| F9   | 20/20       | 3/20         | 20/20       |
| F10  | 20/20       | 20/20        | 20/20       |

F8 默认展示；F9 可以观察 PSO 陷入局部最优。F5、F10 在这个二维版本和边界协议下比较容易，用作不同函数形状的对照。不能把高维 SOP 的难度直接套到二维。这些数值只是本网页算法与配置的难度检查，不是等函数评估预算的算法性能结论。
